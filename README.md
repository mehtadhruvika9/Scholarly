# SCHOLARLY — AI-POWERED SMART COURSE SCHEDULER

Scholarly is an intelligent course scheduling system that converts course or timetable screenshots into complete, clash-free schedules automatically.

It eliminates manual planning and trial-and-error by using AI to extract and organize course data into optimized timetables.


## FEATURES

- Upload course or timetable screenshots  
- AI extracts course details (sections and timings)  
- Automatic clash detection and resolution  
- Generates multiple optimized timetable options  
- Ensures no missing or conflicting courses  
- Clean and user-friendly interface  


## HOW IT WORKS

1. Upload a screenshot of your course or timetable  
2. AI extracts structured data from the image  
3. The system analyzes all possible combinations  
4. Conflicts are detected and eliminated  
5. Multiple valid, clash-free schedules are generated  



## PROBLEM IT SOLVES

Creating a timetable manually is:
- Time-consuming  
- Error-prone  
- Requires repeated trial-and-error  

Scholarly solves this by:
- Automating data extraction  
- Eliminating scheduling conflicts  
- Providing optimized timetable options instantly
